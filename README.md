# Contour AI Projects

This is the workspace for **AI projects at Contour Commercial Interiors**.

It holds the plans, research and decisions behind each AI tool Contour is building, written in plain words. Anyone at Contour should be able to open a file and understand it without a technical background.

- **AI Engineer (System Builder):** Al-khair Pama
- **Client and project lead:** Levi Young, Principal - Business Development (not the CEO)

| File or folder | What it holds |
|---|---|
| [PROJECTS.md](PROJECTS.md) | The overview: every AI project, its priority, and the decisions shared across projects |
| [plan/](plan/) | The build plans for the Lead Finder. [PLAN-V1.md](plan/PLAN-V1.md) built the research engine and website. [PLAN-V2.md](plan/PLAN-V2.md) applies the new company criteria |

| Priority | Project | What it is | File |

These projects are being built as modules of one central web system. It will join HubSpot, Microsoft Teams and Contour's other tools, and give each person their own access. The details are **TBC**. See [PROJECTS.md](PROJECTS.md).

Start with [projects/leads/LEADS.md](projects/leads/LEADS.md). It is the current priority. Its criteria, research settings and questions for Levi are in folders beside it.

## How files here are written

- One-word file names, like `LEADS.md`.
- Short, plain sentences. Technical words are explained the first time they appear.
- Anything not yet confirmed is marked **TBC**.
- Existing files are updated, not copied into new versions.

## Confidential

These files contain Contour's internal plans, deal criteria and meeting notes. Keep this repository private.
