# Deal criteria

Contour's *Qualified Deal Criteria, Option 2, Q4 2026*. Levi shared it on 20 Oct 2026.

## Deal criteria vs company criteria

| | Company criteria | Deal criteria |
|---|---|---|
| Judges | A company | A project |
| When | Before anyone calls | After Contour meets the client |
| Used by | The research agent | Sales and Directors |
| File | [COMPANY.md](COMPANY.md) | This file |

## The 11 rules

A deal must pass all 11. A "no go" rules it out, unless a Director approves it.

| Rule | Passes if | Checked by |
|---|---|---|
| Need | A real office problem, like a move or a full refurbishment | Sales |
| Size | $1.5M to $10M (1,000 to 6,000 m²). Bigger needs a Director. | Research agent (estimate) |
| Timing | Project within 3 years, consultant hired within 18 months, and a clear reason | Research agent |
| Decision makers | Contour has met them | Sales |
| Location | Melbourne, Adelaide or Perth. Sydney sometimes. | Research agent |
| Industry | The office matters to how they work. Some industries need a Director. | Research agent |
| Likelihood | More than 50% likely to go ahead | Sales |
| Procurement | Local people decide, not an overseas office | Research agent flags it, sales confirms |
| Early engagement | Open to strategy and Contour's full service. Design-only or build-only is a no go. | Sales |
| Competition | No happy competitor already in place | Sales |
| Other red flags | Nothing else that lowers the chance of winning | Sales |

The research agent checks 5 rules from public information. Sales checks the other 6 after the first call.
