# Contour AI Projects

This folder holds **one file per AI project** at Contour.

Each file explains a single project in plain words:

- **what kind of project it is**
- why Contour needs it
- how it works, step by step
- what it needs before building
- what is still open (marked **TBC**)

The goal: anyone at Contour can open one file and understand one project, without reading meeting notes or technical documents.

## The projects

| File | Project | What it is | Status |
|---|---|---|---|
| [LEADS.md](LEADS.md) | Company Lead Finder (called "Trigger events" in meetings) | A company lead generator. Every week it finds companies that fit Contour's criteria and show signs of needing a new office, then hands them to sales. | **Priority 1.** Planning. |
| *To come* | Meeting prep | A one-page brief on a client, sent to the team a few days before each meeting | On hold (2026-10-23) |
| *To come* | Deal review | A weekly health check of open deals in HubSpot | Later |

A project gets its own file here when work on it starts.

## Adding a new project file

1. Use a one-word name in capitals, like `LEADS.md`.
2. Start with "What kind of project is this?"
3. Write in short, plain sentences. Explain any technical word the first time it appears.
4. Mark anything unconfirmed as **TBC**.
5. Add it to the table above and link it from [../PROJECTS.md](../PROJECTS.md).
