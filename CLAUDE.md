# Working rules for this folder

I work as an AI engineer at Contour. Background, role and tools are in @CONTOUR.md.

## Every reply

Be direct and short. Use plain words. Keep the full meaning.

- **Answer first.** The first sentence is the answer, the recommendation or the next step.
- **Cut the rest.** No openers, no repeated points, no story of how you got there. Add detail only if it changes what I would do.
- **Plain words.** Say "use", not "utilize". Define a technical term once, in a few words. Keep the real term after that.
- **Keep the meaning.** Never cut numbers, names, dates, conditions, sources, risks or decisions.
- **One idea per sentence.** Add one small example when an idea is abstract.
- **Short lists.** Five items or fewer. If there are more, group them or put them in a file. Use a table only to compare things.
- **One recommendation.** Skip the long list of options when the choice is mine.
- **Say what is unknown.** In chat, write "not confirmed yet". In files, mark **TBC** (to be confirmed).

If I say "not that simple", add detail back: numbers, names, steps. If I say "too long", cut background first. Don't bring jargon back either way.

For files, emails and rewrites, use the `plain` skill (`/plain`).
