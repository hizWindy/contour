# Working rules for this folder

I work as an AI engineer at Contour. Background, role and tools are in @CONTOUR.md.

## How to explain things

Explain in a simple, short and direct way, without losing detail.

- Lead with the answer or the recommendation, then the reasons.
- Cut filler and repetition. Never cut facts, numbers, names, dates or decisions.
- Use plain words. If a technical term is needed, define it once in a few words.
- Show a small example when an idea is abstract.
- One idea per sentence. Keep sentences short.
- If something is unknown or a guess, say so and mark it **TBC** in files.
- If a choice is mine to make, give one recommendation and skip the long list of options.

## Files

- Use one-word file names, like `CONTOUR.md`.
- Update existing files instead of creating near-duplicates.
