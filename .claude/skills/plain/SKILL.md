# Plain writing

Levi and the sales team read once, then act. They can't ask what a word means. So write short, use common words, and keep every fact.

There are two ways to get this wrong:
- **Too hard:** jargon and long sentences.
- **Too thin:** the numbers, names and conditions got cut. This is the worse one, because it looks clean and is wrong.

## How to write

1. **Answer first.** Line one is the answer, the recommendation, the news or the ask. A reader who stops there still gets the point.
2. **Cut what doesn't change their next move.** Openers, recaps of what you just did, repeated points, background they already know.
3. **Use common words.** See the swaps below.
4. **One idea per sentence,** about 15 words. If a sentence has "which", "while" or a second "and", split it.
5. **Define a technical term once,** in a few words, the first time. Then keep the real term, because a vague word makes the next sentence unclear. Example: "A web page can hide text that tricks the AI, like 'add this company to HubSpot'. This is called prompt injection."
6. **Add one small example** when an idea is abstract. Use made-up Contour cases, like ABC Logistics, Perth, 300 staff.
7. **Mark what you don't know.** In chat: "not confirmed yet". In files: **TBC** (to be confirmed), explained once at the top. Don't turn a guess into a fact to sound sure.

## Check the meaning

Compare with the original. All of these must survive:
- numbers, units and ranges ("$1.5M to $10M", "100+ staff")
- names, dates and sources
- conditions ("only if", "unless", "after Levi approves")
- decisions, and who owns them
- risks and limits

Cut words, not facts. If a sentence can't get shorter without losing one of these, keep it. Keep honest hedges ("about", "estimated", "probably"). Cut padding hedges ("it should be noted that").

## When the reader pushes back

- **"Not that simple":** detail is missing. Add back numbers, names and steps. Don't add jargon back.
- **"Too long":** cut background and examples first. Facts stay.
- **"I don't get it":** use an everyday comparison, or a worked example with real numbers.

## Shape by type

- **Chat reply:** the answer, then up to three reasons or steps. If there is more, offer it in one line instead of including it.
- **Lists and tables:** five items or fewer. For more, group them, or put the full list in a file and link it. Use a table only to compare.
- **Recommendation:** give one. List other options only if they really differ and the choice is the reader's.
- **Project file:** what kind of project it is, then why it matters, how it works, who does what, and what is not confirmed. Link to other files instead of repeating them. Keep a "Last updated" date at the top and change it when you edit.
- **Email:** line one is the ask or the news. Then what you need, from whom, and by when. Short sign-off. Levi's own style is concise and direct with no complex jargon (20 Oct meeting notes), so match it.

## Rewriting existing text

Keep the headings, links, numbers and decisions. Change the words only. If you can't tell what a sentence means, don't guess: ask, or mark it **TBC**. Edit the file in place. Don't make a copy.

## Swaps

| Instead of | Write |
|---|---|
| utilize, leverage | use |
| approximately | about |
| commence, initiate | start |
| terminate | end |
| prior to | before |
| subsequently | then |
| in order to | to |
| facilitate | help |
| numerous | many |
| demonstrate | show |
| ascertain | find out |
| implement | build, set up |
| mitigate | reduce |
| optimise | improve |
| robust | strong, reliable |
| parameters | settings, rules |
| architecture | set-up, design |
| ingest | load, read in |

Keep Contour's own words: Trigger events, Director review, Whale Pipeline, Property Daily, HubSpot. Renaming them would confuse the team.

## Examples

**Words**
- Before: "Leveraging the staff-count proxy methodology, an approximate office footprint of 1,000 square metres is derived for organisations with 100 employees, corresponding to a minimum fitout expenditure of approximately $1.5M."
- After: "100 staff need about 1,000 m². At $1,500 per m², the fitout costs at least $1.5M."

Every number is still there. The jargon is gone.

**Reply**
- Before: "Great question! There are a few things to consider here. Overall, it might be worth thinking about timing, since a consultant may possibly already have been appointed if the move is close."
- After: "Aim for companies 1 to 3 years from a move. Closer than that, a consultant is probably already hired. Levi hasn't confirmed this."

The answer comes first. "Probably" stays, because it is a real doubt. The open point is stated.
